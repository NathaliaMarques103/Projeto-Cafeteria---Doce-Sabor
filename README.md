# ☕ Doce Sabor — Cafeteria & Confeitaria Artesanal

> **Landing Page Responsiva e Interativa** desenvolvida para simular a presença digital de um comércio local, focando em conversão de vendas e experiência do usuário.

---

## 📌 Sobre o Projeto

A **Doce Sabor** é uma landing page desenvolvida com foco no comércio de bairro (cafeterias e confeitarias). O objetivo principal da página é permitir que os clientes naveguem pelo cardápio, filtrem os produtos por categoria de forma ágil e façam pedidos diretamente pelo **WhatsApp** do estabelecimento, sem intermediários.

---

## 🚀 Funcionalidades

- 📱 **Layout 100% Responsivo:** Adaptado para navegação fluida em celulares, tablets e computadores.
- 🎨 **Identidade Visual Aconchegante:** Paleta de cores baseada em tons de marrom e creme (`#3b2f2f` e `#fdfbf7`), trazendo a sensação de um ambiente artesanal.
- 🔍 **Filtro Dinâmico de Cardápio (JavaScript):** Permite filtrar os itens instantaneamente por categorias (*Todos*, *Cafés*, *Doces*, *Salgados*).
- 💬 **Integração com WhatsApp:** Botões de pedido que formatam o texto automaticamente e abrem a conversa direto com a cafeteria.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização moderna, uso de Flexbox e CSS Grid para layout responsivo.
- **JavaScript (ES6):** Manipulação de DOM para filtragem de categorias e integração com URL do WhatsApp.
